# 模块：_recovery

## 模块路径

- `_recovery/`

## 模块职责

- 存放本地恢复、取证、排障相关数据快照。
- 用于问题复盘与数据恢复，不参与线上业务运行。

## 当前结构特征

- 存在时间戳子目录（例如 `20260301_075452`）。
- 含有：
  - IndexedDB leveldb 文件
  - Local Storage leveldb 文件
  - token/字符串提取文本
  - 恢复结果 JSON 文件

## 管理约束

- 视为调试资产，默认不作为功能开发输入。
- 不应将该目录数据当作“当前真实业务状态”的唯一来源。
- 涉及敏感信息时应注意脱敏与访问控制。
